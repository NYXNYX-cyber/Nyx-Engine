// SPARK STUDIOS NETWORKING

Unity MCP One-Click Tunnel

Hubungkan Unity MCP di laptop Windows-mu ke Veronika di server secara instan, aman, dan tanpa repot setting router:
● Endpoint Siap: https://unity.nyxstudios.site
CARA 1: ONE-CLICK BATCH FILE (PALING MUDAH)
1. Unduh & Jalankan Script

Klik tombol di bawah untuk mendownload file start-unity-tunnel.bat ke laptopmu, lalu klik 2x (Run) file tersebut:

⚡ Download start-unity-tunnel.bat

Script akan otomatis mendownload engine Cloudflared dan langsung menghubungkan port 8080 laptopmu ke domain terenkripsi HTTPS.

CARA 2: VIA POWERSHELL / CMD (JIKA INGIN MANUAL)
Jalankan 1 Baris Command Ini di PowerShell

Buka PowerShell di laptopmu, lalu copy-paste perintah ini:

irm https://engine.nyxstudios.site/start-unity-tunnel.bat -OutFile run.bat; .\run.bat
Target Endpoint Veronika:
Domain: https://unity.nyxstudios.site
Lokal : http://localhost:8080 (Unity MCP)
